### 🟢 LoRA SD Generator

Я разработал проект, который демонстрирует полный пайплайн тонкой настройки **Stable Diffusion 1.5** с использованием **LoRA** на датасете CelebA для генерации стилизованных лиц на основе текстовых описаний. Он включает автоматизированную подготовку данных (скачивание, ресайз, генерацию подписей через **BLIP**), обучение модели, оценку качества и удобный веб-интерфейс на **Gradio** для генерации изображений (text-to-image и img2img). Главная особенность — низкий порог по оборудованию: **LoRA** с оптимизациями позволяет обучать на **GPU** с 4–6 ГБ VRAM, избегая 24 ГБ, необходимых для полного fine-tuning, при этом давая высококачественные результаты в небольшом файле **LoRA**. Эта настройка идеальна для экспериментов и изучения **LoRA** на ограниченном оборудовании

**Стек технологий: LoRA, Hugging Face Diffusers, BLIP, PyTorch.**

[**Ссылка на проект.**](https://github.com/ArtemMusienko/LoRA-SD-Generator)

### 🟢 OpenRouter chat authorization

Я разработал приложение для чата, которое интегрируется с **OpenRouter.ai**, обеспечивая единый доступ к десяткам мощных моделей искусственного интеллекта с помощью единого ключа **API**. Приложение поддерживает безопасный вход в систему на основе PIN-кода и защиту API-ключа, автоматическую загрузку доступных моделей при запуске, выпадающий список с возможностью поиска для выбора модели, отображение баланса счета в режиме реального времени и полную совместимость с форматами запросов **OpenAI** для плавного переключения между поставщиками без изменения кода. Эта настройка идеально подходит для тестирования, сравнения моделей и эффективного использования ограничений свободного уровня.

**Стек технологий: Python, OpenRouter API.**

[**Ссылка на проект.**](https://github.com/ArtemMusienko/openrouter-chat-authorization)

### 🟢 YOLOv8 vehicle detection

Я реализовал модель **YOLOv8** для обнаружения транспортных средств в условиях недостаточной освещенности. Для повышения точности распознавания модель обучается на специально подготовленных изображениях, имитирующих различные уровни освещенности. Это позволяет улучшить распознавание объектов в реальных условиях. Структура датасета является гибкой: помимо аугментированных данных, можно включить оригинальные изображения, что положительно скажется на качестве модели. Также были проведены дополнительные тесты и применены методы оптимизации, которые позволили значительно улучшить производительность кода.

**Стек технологий: YOLOv8, OpenCV, albumentations.**

[**Ссылка на проект.**](https://github.com/ArtemMusienko/YOLOv8-vehicle-detection)

### 🟢 Voice Assistant with TTS

Я разработал голосового помощника, который распознаёт речевые команды из предопределённого списка, генерирует текстовые ответы с помощью языковой модели и преобразует их в речь через TTS. Он включает захват ввода с микрофона в браузере, транскрипцию, генерацию ответа и голосовой вывод. Главная особенность — использование специализированных многоязычных и ориентированных на русские модели (**Whisper** для ASR, **Saiga Llama** для естественных ответов и **Silero** для TTS), что обеспечивает плавную обработку русской речи и текста без зависимости от проприетарных API. Эта настройка идеальна для создания локализованных прототипов голосового ИИ и экспериментов с технологиями открытого исходного кода в облачных средах.

**Стек технологий: Python, Whisper, Saiga Llama, Silero.**

[**Ссылка на проект.**](https://github.com/ArtemMusienko/Voice-Assistant-with-TTS)
